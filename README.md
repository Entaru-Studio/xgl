# What is XGL
XGL is a graphics library designed for more convenient creation and use of graphics. It stands for Xsynda Graphics Library.

# How to download
## Manually
1. Download `xgl.lua` file from main repository
2. Paste it into your computer files
3. Done
## Via wget
1. Enter this command to the terminal `wget https://raw.githubusercontent.com/Entaru-Studio/xgl/refs/heads/main/xgl.lua`
2. Done

# Что такое XGL
XGL это графическая библиотека, предназначенная для более удобного создания и использования графики. Она расшифровывается как Xsynda Graphics Library.

## Вручную
1. Скачайте файл `xgl.lua` с главного репозитория
2. Вставьте его в файлы вашего компьютера
3. Готово
## Через wget
1. Введите эту команду в терминал `wget https://raw.githubusercontent.com/Entaru-Studio/xgl/refs/heads/main/xgl.lua`
